# website_alist_media (Odoo 19)

Sandbox-verified package **19.0.3.0.1**: AList tab in native MediaDialog (website editor), CDN URLs, body/section video support.

## Deploy files

| File | Purpose |
|------|---------|
| `website_alist_media-19.0.3.0.1.zip` | Module zip |
| `deploy_website_alist_media.sh` | One-click install/upgrade for `prod-odoo` / DB `letaoge` |

Put both in the same directory on the VPS (e.g. `$HOME`), then:

```bash
bash deploy_website_alist_media.sh
```

Not the product-page `media_picker` module.
